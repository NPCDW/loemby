## Context
当前 `play_info_init` 已共用，但 Android 另写了 `run_session`，遗漏字幕预缓存和媒体缓存设置；`call_player` 的参数构建也分成两份，Android 不读取 `mpv_args`，预读取固定为 `no`，音量强制限幅。此次修改让桌面和 Android 使用同一份播放处理、配置与参数来源，仅保留必要的平台启动和生命周期适配。

## 实施方案

### 1. 统一 `call_player` 的配置和启动参数
- 在 `src-tauri/src/service/player_svc.rs` 中共用入口校验、服务器配置读取、`prepare_playback_plan` 和 mpv 参数构建。
- 共用 `mpv_args` 配置文本、音量、User-Agent、预读取、`script-opts`、自动加载策略及播放协议配置；保留下载时关闭预读取的规则。
- 保持桌面的配置优先级：自定义配置先加载，应用显式参数随后覆盖。Android 不再另设音量/预读取/UA，也不再强制将持久化音量限制为 100。
- 桌面保留外部/内置 mpv 路径、portable_config 和进程启动；Android 使用私有目录、libmpv 与原生 Activity，不执行桌面程序。
- 扩展插件 `PrepareOptions`，传递配置文件路径和有序选项，经 Kotlin 转发到 JNI，在 `mpv_initialize` 前使用 mpv 的配置解析和选项接口应用。不会按空格或简单字符串拆分 `mpv_args`。
- Android 仅强制保护 Surface/wid、Android 渲染上下文、IPC socket、会话 idle 和加载阶段 pause 等必要项；硬解作为可被用户配置覆盖的平台默认。配置应用失败给出具体错误。
- 将独立且可移植的 `cache_speed.lua` 写入 Android 配置目录并显式加载，使共用的网速显示参数实际生效；不搬运桌面 uosc 和窗口配置。

### 2. 两端实际调用同一个 `playback_process`
- 将媒体注册、当前媒体状态和事件处理移入共用播放会话；删除 Android 的独立 `run_session`，不是仅复制或抽取几段代码后仍保留两套循环。
- 两端在加载播放列表前建立 IPC 读取并启动共用 `playback_process`。桌面先以 idle 模式启动，再加载列表，避免每次 HTTP 媒体请求新建处理循环或遗漏早期事件。
- 复用 `mpv_ipc::Client` 的请求/事件分发，传输连接复用现有 `get_pipe_rw` 的 Unix socket / Windows named pipe 实现，保持跨平台 sender 类型一致。
- 共用媒体开始、初始化、两秒轮询、30 秒进度上报、结束状态和断连处理；继续调用原 `play_info_init`、`save_playback_progress_async`。
- 从 `play_info_init` 移走平台分叉的轮询任务，删除 Android 的永不完成占位任务，由共用循环管理轮询。
- 将原字幕预缓存和按码率/配置计算前后向缓存纳入共用流程。字幕预缓存仍在媒体解析阶段触发，缓存参数在初始化对应媒体时应用。
- 使用播放条目 ID 和本地媒体 URL 关联注册信息，校验异步进度所属条目；覆盖预读取、切集、重定向和桌面 uosc 切版本，不能仅依赖固定的播放列表下标。
- 保留续播只应用一次、音轨/字幕选择、历史和第三方同步逻辑；每个媒体结束只结算一次，不能把旧条目的进度写给新条目。

### 3. 平台适配与清理
- `android_player.rs` 收缩为原生准备、加载/ready token 握手和关闭适配；保留音频焦点协议、关闭超时隔离及 libmpv 销毁后释放 Surface 的顺序。
- 共用会话登记媒体及外部音轨/字幕请求，退出清理该会话的播放计划、请求、重定向缓存和临时文件。
- 桌面保持最终 EOF/错误时退出 mpv、返回应用窗口的行为；退出控制不依赖网络上报成功。不会删除用户的 portable_config 或自定义配置。
- 保留当前 Android 不支持下载的限制，不改变前端播放请求格式，不覆盖已有未提交的前端改动。

## 关键文件
- `src-tauri/src/service/player_svc.rs`：共用入口、参数构建、会话与 `playback_process`、媒体初始化。
- `src-tauri/src/service/android_player.rs`：精简为平台适配。
- `src-tauri/src/service/mpv_ipc.rs`、`service/mod.rs`、`src-tauri/src/lib.rs`：跨平台 IPC 和共用会话初始化。
- `src-tauri/plugins/tauri-plugin-mpv/src/lib.rs`、Android 的 `MpvPlugin.kt`、`MpvNative.kt`、`MpvPlayerActivity.kt`、`mpv_jni.cpp`：配置和选项贯通。

## 验证
- 新增 Rust 测试：共用参数默认值/覆盖顺序、预读取与下载、超过 100 的合法音量、特殊字符、缓存计算；事件状态覆盖切集、redirect、过期条目事件和断连，IPC 覆盖请求与事件独立分发。
- 运行相关 Rust 单元测试、Linux `cargo check`、Android `aarch64-linux-android` 编译检查，以及现有 Android 前端 Node 测试。
- 构建 debug APK，验证 Kotlin/JNI 参数贯通与 native bundle；构建不提交、不推送，不重生成 Android 工程。
- 有设备时验证实际配置、续播、字幕/音轨、缓存、连续切集、桌面版本切换、退出再开与准备失败清理；无设备时明确标注未做真机验证。环境或依赖导致的检查失败如实记录。
