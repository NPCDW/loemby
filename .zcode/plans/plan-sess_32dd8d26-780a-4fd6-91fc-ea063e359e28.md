## Context
用户要求把当前项目打成 armv8 安装包，并确认 Tauri Android 配置的位置。armv8 按 Android ABI `arm64-v8a` / Rust target `aarch64-linux-android` 处理。当前 Android 历史前端已实现，但 `src-tauri/gen/android/` 尚不存在；环境目录中已有 JDK 21、SDK 36、NDK 27.2 和对应 Rust target，实际可执行性仍需验证。

## 实施方案
1. **核实工具链并初始化 Android 工程**
   - 检查 Java、Rust、已安装 Tauri CLI 的 Android 参数和版本兼容性。
   - 复用 `/opt/android-sdk` 现有 SDK/NDK；通过本次命令环境指定路径，不把机器路径提交为通用项目配置。
   - 执行 `pnpm exec tauri android init`，生成 `src-tauri/gen/android/`。仅在必要时下载缺失的构建工具/依赖；不上传源码、不发布安装包。
2. **完成最小 Android 原生兼容修正，保留桌面行为**
   - 新增 `src-tauri/tauri.android.conf.json`，覆盖不适合 Android 的桌面资源与 updater 打包选项；保留应用标识 `com.loemby.app`、版本及真实前端入口。
   - 在 `src-tauri/src/service/mod.rs`、`src-tauri/src/lib.rs`、`src-tauri/src/controller/invoke_ctl.rs` 中隔离桌面 updater 引用。Android 的未支持操作明确返回错误，而不是伪造成功。
   - 在 `src-tauri/src/service/player_svc.rs` 中隔离桌面 mpv 入口；Android 明确提示原生播放尚未适配，不实现新播放器。
   - 检查 `src-tauri/src/config/app_config.rs` 对 Android 打包资源的首次读取方式，必要时让 Android 从编译内置的默认配置初始化，继续使用原有真实 SQLite/历史接口，不使用模拟数据。
   - 根据实际编译错误，仅修复必要的 Android 条件编译或依赖问题；若需要重大架构改动或正式签名材料，先报告并重新确认。
3. **生成 arm64-v8a 可安装测试 APK**
   - 按安装的 CLI 支持参数执行相当于 `pnpm exec tauri android build --target aarch64 --debug --apk` 的构建。
   - 使用 Android 开发签名，不生成正式发布密钥、不提交密钥、不声称可用于商店发布。
   - 将 APK 复制到便于领取的项目交付目录，文件名包含版本、`arm64-v8a` 和 `debug`；不覆盖已有安装包。
4. **记录生成配置的位置和复现命令**
   - 更新 `src/android/README.md`，说明 Tauri 基础配置、Android 覆盖配置，以及生成目录中 Gradle、Manifest、SDK 本地路径配置的位置。
   - SDK 路径、构建缓存及签名文件保持本地，不混入可复用配置。

## 主要文件
- 新增：`src-tauri/tauri.android.conf.json`、`src-tauri/gen/android/` 初始化生成的 Android 工程、APK 交付文件。
- 必要修改：`src-tauri/src/service/mod.rs`、`src-tauri/src/lib.rs`、`src-tauri/src/controller/invoke_ctl.rs`、`src-tauri/src/service/player_svc.rs`、`src-tauri/src/config/app_config.rs`、`src/android/README.md`；依实际编译结果最小调整 Cargo 配置。
- 保留当前未提交的前端实现，不改桌面页面与桌面播放逻辑，不增加 Android 播放功能。

## 验证
- 运行前端类型检查和现有 Android 历史回归测试，确认打包仍使用真实应用入口。
- 完成 `aarch64-linux-android` 原生编译和 Gradle APK 构建。
- 使用 Android 构建工具检查 APK 包名、版本、`arm64-v8a` 原生库和签名有效性，提供实际产物路径、大小和 SHA-256。
- 如没有设备/模拟器，明确注明只验证构建、ABI 和签名，未验证安装启动、真实数据库初始化或原生播放。若构建失败，报告准确阻塞，不交付未签名或伪造的可安装包。
